# 📚 BookFlow – Sistema de Gerenciamento de Biblioteca Acadêmica

Este projeto simula um sistema de biblioteca acadêmica com controle de usuários, livros, autores, categorias, empréstimos, notificações, multas e eventos.

## 📂 Estrutura dos arquivos

- `insert_bookflow.sql` → Povoa as tabelas principais com dados fictícios.
- `select_bookflow.sql` → Contém consultas SQL (SELECT com WHERE, ORDER BY, JOIN).
- `update_delete_bookflow.sql` → Contém comandos de UPDATE e DELETE.
- `README.md` → Explicação do projeto.
